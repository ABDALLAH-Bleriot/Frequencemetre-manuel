# 🩺 Fréquencemètre manuel

Application Android médicale : comptage de fréquences, calculs de débits et gestogramme.

Compatible **Android 7.0+** • Thème glassmorphism bleu/cyan • Police Poppins

## ✨ Fonctionnalités

- **Compteur manuel** : fréquence en appuis/min avec chronomètre et tic sonore
- **Générateur de fréquence** : métronome visuel (barre animée) + tic sonore, 1 à 300 /min
- **Calculs** : débit de perfusion, débit P.S.E. (drogues vasoactives), gestogramme
- **Info** : fonctionnalités et coordonnées de l'auteur

## 🚀 Installer l'APK

1. Onglet **Actions** → **Build APK** → **Run workflow**
2. Coche verte ✅ → cliquer sur le run → **Artifacts** → **app-debug-apk**
3. Extraire le ZIP et installer `app-debug.apk` sur le téléphone
